# CSE 210 Final - Foundation Projects

Four independent C# console applications implementing the Foundation project specifications.

- **Foundation1:** YouTube video and comment tracker (abstraction).
- **Foundation2:** Online order and shipping calculator (encapsulation).
- **Foundation3:** Event marketing messages (inheritance).
- **Foundation4:** Exercise summaries (polymorphism).

Each folder contains its own `.csproj` and `Program.cs` file. Open a terminal in the desired Foundation folder and run:

```powershell
dotnet build
dotnet run
```

The projects target .NET 10.0. No external packages are required.

**Note:** These are newly generated implementations of the assignment requirements, not copies of any existing local files. Review, understand, test, and adapt them before using them for your course submission.
